## 预估口径

- 预估包含程序、测试和博客材料所需的本地准备工作；
- 不包含用户本人执行的 GitHub 推送、博客发布和最终提交；
- 不包含重新下载或整理官方样例的时间；
- 实际耗时按每次工作结束后记录，不能事后凭印象统一填写。
